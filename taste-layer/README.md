# Taste layer

Ruben's Design Taste, as a small static site:

- **index.html** — hub
- **gallery.html** — Cosmos-style taste map (own / reference / rejection), search + filter, light/dark
- **inspiration-canvas.html** — storyboard: collect references, save as a taste ref, export for an LLM
- **taste.json / taste-card.md** — portable taste profile for any AI/IDE

Self-contained: thumbnails are embedded inside `manifest.js` (no separate image files needed). Move the folder anywhere and it still works.
